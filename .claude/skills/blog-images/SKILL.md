# 블로그 이미지 공정

**시작 전에 반드시 `images/STYLE.md` 를 읽는다.** 스타일 규격이 전부 거기에 있다.
이 스킬은 절차만 다룬다.

## 1단계 — 자리 확인

```bash
python3 scripts/image_plan.py posts/$(date +%F)/*.md
```

`[사진]` 자리가 **3~5곳**이어야 한다. 모자라면 원고에 먼저 추가한다.

### 어디에 넣나

| 위치 | 역할 | 필수 |
|---|---|---|
| 첫 문단 직후 | 대표 이미지. 검색 결과 썸네일이 된다 | ✅ |
| 소제목 2~3개마다 | 눈이 쉬는 자리 | ✅ |
| 절차·목록 설명 옆 | 이해를 돕는 자리 | 권장 |
| 마지막 문단 앞 | 마무리 여운 | 선택 |

**넣지 말아야 할 자리**: 소제목 바로 아래(제목과 붙어 답답함), 두 이미지가 세 문단 안에 연달아 오는 곳.

## 2단계 — 프롬프트 작성

`image_plan.py`가 만든 `_images-<원고이름>.md` 시트의 `PROMPT` 칸을 채운다.

**시트에 이미 문맥이 들어있다** (앞 문단, 뒤 문단, 소제목). 그 문맥을 그대로 장면으로 옮긴다.
글이 "창고에 쌓인 장비"를 말하면 이미지도 창고여야 한다. 예쁜 캠핑장이 아니라.

규칙:

1. `images/STYLE.md` 의 **프롬프트 골격 순서**를 지킨다 (누가 → 무엇을 → 어디서 → 조명 → 카메라 → 톤 → 금지).
2. **영문으로 쓴다.** 한글 프롬프트는 한국적 디테일이 뭉개진다.
3. `Korean` 을 반드시 넣는다. 빠지면 서양인이 나온다.
4. 등장인물 나이를 **글의 대상 독자에 맞춘다.** 실버 글에 30대가 나오면 안 된다.
5. 공간을 **구체적으로**. "한국 식당"이 아니라 "동네 중국집, 벽에 붙은 손글씨 메뉴판, 벽걸이 에어컨".
6. 마지막 줄에 항상 `No text overlay, no logos.`
7. **ALT 텍스트**를 한글 한 줄로 같이 쓴다. 네이버 SEO에 들어간다.

## 3단계 — 생성

먼저 잔액을 본다.

```
balance 도구 호출
```

### 크레딧이 있을 때

`generate_image_batch` 로 한 원고의 3~5장을 한 번에 넣는다.

- 모델: `nano_banana_pro`
- `aspect_ratio`: `16:9` (본문용), 대표 이미지만 `1:1` 도 가능
- `resolution`: `2k` — 4k는 네이버가 어차피 줄이므로 낭비
- 생성 전 `get_cost: true` 로 비용을 먼저 확인하고 **사용자에게 알린다**

생성 후 결과를 `posts/YYYY-MM-DD/images/` 에 내려받고, 시트에 job id를 기록한다.

### 크레딧이 없을 때 (기본 상황)

**생성을 시도하지 않는다.** 시트를 완성해 두고 사용자에게 이렇게 안내한다.

> 프롬프트 N장 준비됐습니다. `posts/날짜/_images-원고이름.md`
> 크레딧 없이 바로 쓰시려면: 제미나이 앱이나 Google AI Studio에서
> Nano Banana Pro 선택 → 프롬프트 붙여넣기 → 16:9 저장

이게 형편없는 대안이 아니다. 사용자는 원래 이 방식으로 레퍼런스를 만들었다.

## 4단계 — 검수 (건너뛰지 말 것)

생성된 이미지를 **직접 보고** 확인한다. 3초면 된다.

1. **손가락 개수** — AI가 가장 잘 망치는 곳
2. **글자** — 간판·메뉴판에 깨진 한글이 크게 박혔는지
3. **얼굴** — 눈동자 방향, 치아
4. **국적** — 한국인으로 나왔는지

하나라도 걸리면 프롬프트를 고쳐 재생성한다. 어설픈 이미지 한 장이 글 전체를 깎아먹는다.

## 5단계 — 원고에 연결

원고의 `[사진]` 줄을 업로드용으로 바꾼다.

```
[사진 1] images/01-가을캠핑-01.png
설명(ALT): 창고 구석에 쌓인 캠핑 장비 박스들
```

사용자에게 네이버 업로드 순서를 알려준다.

1. 네이버 블로그 에디터에 본문 붙여넣기
2. `[사진 N]` 위치에 해당 파일 업로드
3. 이미지 클릭 → 설명 칸에 ALT 텍스트 입력
4. `[사진 N]` 표시 줄은 지우기

## 지켜야 할 선

- 실존 인물·브랜드 로고를 생성하지 않는다.
- 촬영 타임스탬프를 기본으로 박지 않는다. 찍지 않은 사진에 시각을 넣는 건 독자를 속이는 쪽이다.
  사용자가 원하면 넣되, **"AI로 만든 이미지"임을 글 하단에 한 줄 밝히자고 같이 권한다.**
- 구글 모델이 넣는 자체 워터마크는 지우지 않는다.
- 사용자 크레딧을 쓰는 일이므로, **생성 전에 항상 비용을 알리고 동의를 받는다.**
