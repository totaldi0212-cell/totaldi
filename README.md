# totaldi — 클로드용 GEM 시스템

구글 제미나이의 **Gem**(맞춤 AI 역할을 저장해두고 반복해서 쓰는 기능)을
클로드에서 그대로, 그리고 조금 더 강력하게 쓰기 위한 저장소입니다.

핵심 차이 한 줄: **제미나이 Gem은 골라서 쓰고, 여기 GEM은 알아서 튀어나옵니다.**
"이 메일 좀 써줘"라고만 해도 클로드가 `email-writer` 젬을 스스로 찾아 적용합니다.

---

## 1분 사용법

```bash
./scripts/gem.sh list            # 어떤 젬이 있나
./scripts/gem.sh new my-gem      # 새로 만들기
# gems/my-gem.gem.md 편집
./scripts/gem.sh sync            # 빌드 → 이때부터 클로드가 자동 인식
```

클로드 대화창에서는 이렇게도 됩니다.

- `/gem` — 젬 목록 + 관리 메뉴
- `/gem-new 이름` — 대화로 질문 받아가며 젬 설계
- 그냥 "젬 만들어줘" 라고 해도 됩니다

---

## 구조

```
gems/                       ← 여러분이 관리하는 원본 (이것만 고치면 됨)
  _template.gem.md
  email-writer.gem.md
  report-summarizer.gem.md
  meeting-notes.gem.md

.claude/skills/gem-*/       ← sync가 만드는 자동 생성물 (직접 고치지 마세요)
.claude/skills/gem/         ← 젬을 만들고 관리하는 메타 스킬
.claude/commands/           ← /gem, /gem-new 슬래시 명령
scripts/gem.sh              ← 관리 CLI
```

동작 원리는 단순합니다. 젬 파일 하나 = 클로드 스킬 하나.
`sync`가 `gems/*.gem.md`의 frontmatter와 본문을 읽어 `.claude/skills/gem-<이름>/SKILL.md`로 변환하고,
클로드는 각 스킬의 `description`을 보고 **지금 이 대화에 필요한 젬인지 스스로 판단**합니다.

---

## 기본 제공 젬

| 젬 | 하는 일 | 이런 말에 반응 |
|---|---|---|
| `email-writer` | 업무 이메일·회신 초안 | "메일 써줘", "정중히 거절", "독촉 메일" |
| `report-summarizer` | 임원 보고용 요약 | "요약해줘", "핵심만", "한 장으로" |
| `meeting-notes` | 회의록 + 액션아이템 | "회의록 정리", "녹취 풀어줘" |

---

## 좋은 젬을 쓰는 요령

1. **`description`에 공을 들이세요.** 클로드는 이 한 문장만 보고 자동 호출 여부를 정합니다.
   여러분이 실제로 칠 법한 말("메일 써줘")을 그 안에 직접 넣어두세요.
2. **규칙은 검증 가능하게.** "좋게 써라"(X) → "5문장 이내, 느낌표 금지"(O)
3. **출력 형식을 코드블록으로 박아두세요.** 재현성이 확 올라갑니다.
4. **예시 1개가 지시문 10줄보다 강합니다.**
5. 젬은 작게 쪼개세요. 만능 젬 하나보다 역할이 뚜렷한 젬 3개가 훨씬 잘 걸립니다.

## 클로드의 다른 "Gem 비슷한 것"들

이 저장소가 쓰는 스킬 말고도, 용도에 따라 골라 쓸 수 있습니다.

| 기능 | 제미나이로 치면 | 언제 쓰나 |
|---|---|---|
| **Skills** (이 저장소) | Gem | 상황에 따라 자동으로 꺼내 쓰고 싶은 역할 |
| **Projects** (claude.ai) | Gem + 지식 파일 | 웹/앱에서 자료 묶음과 함께 쓸 때 |
| **CLAUDE.md** | 시스템 지시 | 프로젝트 전체에 항상 적용할 규칙 |
| **Subagent** (`.claude/agents/`) | — | 별도 컨텍스트에서 독립 실행시킬 전문가 |
| **Slash command** (`.claude/commands/`) | 저장된 프롬프트 | 내가 직접 호출하는 정형 작업 |

Gem과 가장 결이 같은 건 **Skills**이고, 자동 호출·도구 사용·버전 관리(git)가 된다는 점에서 한 단계 위입니다.
